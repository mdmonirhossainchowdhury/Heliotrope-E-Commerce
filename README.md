# Heliotrope-E-Commerce

A MERN STACK E-Commerce Project.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and set any required environment variables.
3. Run the app:
   `npm run dev`

## About

This repository contains the Heliotrope E-Commerce application with React, Firebase, and Vite.
